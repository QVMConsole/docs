QVMConsole安装与使用功能与原理

QVMConsole

基于 KVM/QEMU 构建的轻量级虚拟机管理面板，提供虚拟机全生命周期管理、 VNC 远程控制台、VPC 网络隔离、安全认证与异步任务中心等一站式能力。

快速开始开发文档

虚拟机全生命周期

创建、克隆、迁移、重装、导入导出，支持模板克隆、原生链式克隆和从 ISO 普通创建三种模式。

浏览器 VNC 控制台

基于 noVNC 的浏览器远程桌面，支持密码粘贴、文本发送、常用组合键和独立窗口模式。

网络与安全组

VPC 隔离网络、端口转发、静态 IP 绑定、带宽限速和网络诊断抓包，完整覆盖虚拟网络管理。

轻量云模式

管理员登记分配，用户确认开通，按单台 VM 精细管控流量、带宽、端口转发和运行时长配额。

多层安全体系

管理员 2FA 强制绑定、用户邮箱验证、邀请注册流程和高风险操作二次验证，全面保障系统安全。

异步任务中心

所有耗时操作提交到任务队列，通过 SSE 实时推送进度，底部任务面板无需离开当前页面。

模板与存储

链式克隆模板树、模板导入导出、存储池硬盘管理、ISO 镜像库和用户级存储配额。

调度与救援

智能内存气球调度、Windows 弹性内存、定时任务和救援系统一键修复无法启动的虚拟机。

Vue 3 前端框架
libvirt 虚拟化 API
OVS 虚拟交换机
noVNC 远程控制台
SQLite 数据存储
