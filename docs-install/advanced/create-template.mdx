# 制作模板

:::tip 前置阅读
请先阅读[模板管理](/docs/install/advanced/template-management)了解模板的基本概念和使用方式。
:::

模板是 QVMConsole 实现**毫秒级创建虚拟机**的核心功能。通过将一台精心配置的虚拟机制作为模板，您可以快速克隆出多台相同配置的虚拟机。

## 工作原理

QVMConsole 的模板制作本质上是将虚拟机的磁盘文件进行稀疏复制（`cp --sparse=always`），生成一个只包含实际数据的精简磁盘文件。基于该模板创建虚拟机时，系统支持两种克隆模式：

- **链式克隆**：速度快、占用空间小，但依赖模板文件完整性
- **完整克隆**：完全独立，不依赖模板，但占用更多存储空间

## 准备工作

### 安装必要驱动

在制作模板前，请确保虚拟机已安装所需的驱动和软件：

- **Linux 系统**：安装 [QEMU Guest Agent](/docs/install/quick-start/install-linux#安装-qemu-guest-agent)
- **Windows 系统**：安装 [VirtIO 驱动和 Guest Agent](/docs/install/quick-start/install-windows#补全-virtio-驱动)

### Windows 通用化

:::warning 重要提示
Windows 系统在制作模板前**必须**进行 Sysprep 通用化处理，否则基于模板创建的虚拟机可能出现 SID 冲突等问题。
:::

Sysprep 是微软官方提供的系统准备工具，用于移除计算机特定信息（如 SID、驱动缓存等），使系统映像可在不同虚拟机上安全部署。

**操作步骤：**

1. 按 `Win + R` 打开运行框，输入 `Sysprep` 并回车
2. 在打开的文件夹中，双击 `sysprep.exe`
3. 在弹出的对话框中：
   - 勾选「通用化」（Generalize）
   - 下拉框选择「关机」（Shutdown）
4. 点击「确定」开始通用化流程

:::danger 注意
通用化过程**必须通过 VNC 画面操作**。如果使用远程桌面，通用化过程中会断网，有概率导致通用化失败！
:::

#### Windows 桌面版特殊流程

Windows 桌面版（如 Windows 10/11）的通用化流程与 Server 版有所不同：

| 系统版本 | 通用化时机 |
|---------|-----------|
| Windows Server | 进入桌面后安装驱动和软件，然后直接执行 Sysprep |
| Windows 桌面版 | 必须在 OOBE 阶段（系统配置向导）按 `Ctrl + Shift + F3` 进入审计模式，在审计模式下安装驱动和软件后再执行 Sysprep |

## 制作模板

完成准备工作后，按照以下步骤制作模板：

1. **关闭虚拟机** — 制作模板前必须先将虚拟机关机
2. **进入制作模板界面** — 在虚拟机列表中，点击目标虚拟机右侧的「更多」按钮（三个点），选择「制作模板」

   ![制作模板入口](https://images.xiaozhuhouses.asia/i/2026/06/13/h5h5l7.png)

3. **填写模板信息**：
   - **模板名称**：管理员侧使用的标识，仅支持字母、数字、点、下划线和短横线
   - **用户侧显示**：在「从模板克隆」下拉框中显示的标题
   - **模板类型**：选择对应的系统类型（Linux / Windows / FnOS / Other）

4. **等待制作完成** — 提交后可在任务中心查看进度

## 制作多版本模板

如果您需要基于一个主模板制作更多版本（如添加特定软件），可以使用**链式克隆**方式：

1. 使用主模板[创建虚拟机](/docs/install/advanced/template-management#从模板创建虚拟机)，克隆模式选择「链式克隆」
2. 在新虚拟机中安装所需软件或进行配置调整
3. 关机后重复[制作模板](#制作模板)步骤

:::info 说明
链式克隆的虚拟机依赖主模板，制作新模板时会将依赖关系解除，生成独立的模板文件。
:::

## 基于模板制作独立模板

如果您需要一个完全独立、不依赖任何模板的新虚拟机，可以使用**完整克隆**方式：

1. 使用模板[创建虚拟机](/docs/install/advanced/template-management#从模板创建虚拟机)，克隆模式选择「完整克隆」
2. 在新虚拟机中进行配置调整
3. 关机后重复[制作模板](#制作模板)步骤

完整克隆的虚拟机磁盘完全独立，适合对数据安全性要求较高的场景。
