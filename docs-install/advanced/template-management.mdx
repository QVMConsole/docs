# 模板管理

您可以通过模板实现**毫秒级创建虚拟机**。作者已制作了原版镜像可供大家导入使用。

## 下载预置模板

请通过以下链接下载预置模板压缩包：

- **夸克网盘**：[https://pan.quark.cn/s/e20fb6374394](https://pan.quark.cn/s/e20fb6374394) (由于网盘限制下载后请解压出tar.gz进行导入)

## 导入模板

将下载好的模板压缩包通过以下方式上传到设备中：

- **网页上传**：在管理面板的模板管理页面直接上传
- **SFTP 上传**：通过 SFTP 工具将文件传输到服务器指定目录

上传完成后，在模板管理页面选择合适的导入方式即可完成模板导入。

## 从模板创建虚拟机

模板导入成功后，在**新建虚拟机**表单中选择 **「从模板快速克隆」** 即可使用模板创建虚拟机。系统会自动基于模板生成虚拟机磁盘，并支持批量创建多台相同配置的虚拟机。

:::tip 快速上手
从模板克隆的虚拟机会自动完成系统初始化，包括主机名设置、账号密码注入等，实现开箱即用。
:::

:::warning 温馨提示
Linux 镜像当前使用的是**在线初始化系统**，请务必确保您的网络正常、能正常分配到 IP 即可。请勿在首次创建虚拟机时使用 VLAN 网段（因为无法获取到 IP）。
:::

## 链式克隆注意事项

:::danger 重要警告
若您选择**链式克隆**方式创建虚拟机（详见 [模板快速克隆](/docs/tech/virtual-machine/creation-modes#模板快速克隆)），您必须确保**模板不能丢失或损坏**，否则将造成克隆后的虚拟磁盘损坏！

请务必将模板存放到**安全的硬盘阵列**中，重要数据建议通过**挂载数据盘**方式单独存放，避免模板丢失造成数据损坏！
:::

链式克隆的虚拟机磁盘依赖模板磁盘作为 backing file，模板一旦丢失或损坏，所有基于该模板链式克隆的虚拟机磁盘都将无法正常使用。如果您对数据安全性要求较高，建议选择**完整克隆**方式，虽然会占用更多存储空间，但克隆后的虚拟机完全独立，不依赖模板。
