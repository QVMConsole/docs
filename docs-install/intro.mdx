# 安装

本页面介绍 QVMConsole 的安装方法和系统要求。

## 系统要求

### 兼容系统

QVMConsole 当前仅支持 **Debian 系列** 发行版：

- Ubuntu 24
- Ubuntu 26

**内核版本要求**：Linux 6.6 - Linux 7.0.22

:::warning 重要提示
- 暂时不兼容其它发行版系统
- 非兼容的内核版本外可能存在兼容问题，请尽可能使用兼容的发行版系统
- 建议将所有软件包升级到最新版本
:::

### 系统环境要求

:::danger 纯净系统要求
**必须是纯净的系统环境**，可以与 Docker 共存，但**不要安装过其它涉及网络相关的软件包**。

强烈建议使用纯净系统，避免存在功能冲突导致安装失败或运行异常。
:::

## 准备环境

在安装之前，请确保将系统所有软件包和内核更新到最新版本：

```bash
sudo apt update && sudo apt full-upgrade
```

:::warning 更新提示
- 必须将系统所有软件包和内核更新到最新版本
- 如果更新过程存在问题，可能是软件包源的问题或者系统软件包损坏，请自行搜索教程解决后再进行安装
:::

## 安装方法

<AgreementGate hint="阅读协议并查看安装方法">

### 第一步：下载安装文件

```bash
# 下载安装脚本
wget https://download.qvmconsole.xiaozhuhouses.asia/app1/latest/install.sh

# 下载程序包
wget https://download.qvmconsole.xiaozhuhouses.asia/app1/latest/kvm-console-linux-amd64.tar.gz
```

### 第二步：执行安装

```bash
bash install.sh
```

:::info 注意事项
安装期间安装脚本会自动处理依赖和网络等基础服务。请确保在**独立的会话环境**中运行安装命令，避免因中断造成安装失败。
:::

### 第三步：访问系统

安装完毕后，使用以下方式访问：

- **访问地址**：`http://你的服务器IP:设置的端口`
- **默认账户**：`admin`
- **默认密码**：`admin123`

:::danger 安全提示
请务必登录后**第一时间修改默认密码**！默认密码仅用于初始登录，不修改存在严重安全风险。
:::
