# 面板问题

## 升级后存在很多问题以及页面不匹配
大部分情况下可能是浏览器缓存造成的，您可以按照以下操作清理浏览器缓存
### 方法一：
按`F12`然后找到下图中的并操作
![](https://images.xiaozhuhouses.asia/i/2026/06/22/zozki2.png)
然后不要关闭刷新页面之后再关闭F12菜单

### 方法二：
按`F12`然后找到下图中的并操作
![](https://images.xiaozhuhouses.asia/i/2026/06/22/10e01q8.png)
刷新页面即可
