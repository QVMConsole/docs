# 赞助支持

> **开源之路，因你而续**

QVMConsole 是一个充满热情的开源项目，致力于为个人用户提供强大而易用的虚拟机管理体验。然而，持续的维护与创新需要不菲的精力与资源。您的每一份支持，都是推动项目前行的动力源泉。

为了感谢那些愿意为项目发展贡献力量的伙伴，我们特别准备了**赞助版**——不仅包含更多实用功能，更承载着我们对支持者的诚挚谢意。

## 版本对比

### 开源版

**面向个人用户，功能齐全，完全免费**

开源版由社区与作者共同维护，适合日常个人使用，**无数量限制**，代码完全开放透明。

- 社区驱动，持续更新
- 核心功能完整覆盖
- 适合个人日常使用场景

### 赞助版

**专属功能，优先支持，致敬每一位赞助者**

赞助版由作者基于开源版闭源亲自维护，核心团队参与少量维护，提供更专业、更高效的功能体验。

:::tip 赞助版独享权益
**面板功能**
- **自动更新**：始终保持最新版本，无需手动操作
- **LVM 卷高级管理**：存储池中支持 LVM 卷的高级维护和管理功能
- **虚拟机磁盘备份**：轻松备份重要数据，保障业务连续性
- **OVF 导出功能**：将虚拟机导出为标准 OVF 格式，便于迁移与分享

**专属服务**
- **优先解答**：专属赞助者群，享受作者优先技术支持
- **官网展示**：官网赞助者悬挂，彰显您的贡献
- **前沿体验**：更多前沿功能抢先体验，第一时间感受创新
:::

## 常见问题

### 赞助后如何获取赞助版？

赞助成功后，请通过专属赞助者群联系我们，我们将为您提供详细的安装与使用指导。

### 赞助版是否可以退款？

赞助属于自愿支持行为，一经订阅，恕不退还。但您可以随时取消后续订阅。

## 注意事项

:::warning 联网激活要求
赞助版采用**联网激活机制**，需要设备**实时联网**以定期向激活服务器验证授权状态。若设备断网，可能导致激活失效，显示为未激活状态。
:::

### 离线应急处理

若不慎遇到断网情况，可按以下步骤应急处理：

1. **下载开源版安装包**：在联网设备上获取开源版程序包
2. **离线安装升级**：将安装包传输至目标设备，直接执行安装即可离线完成版本切换
3. **恢复赞助版**：待网络恢复后，重新安装赞助版即可，两个版本互不影响

:::note 版本切换说明
- 开源版与赞助版支持无缝切换，数据不会丢失
- 离线期间使用开源版不影响后续赞助版的正常使用
- 建议保持网络连接以获得最佳使用体验
:::
