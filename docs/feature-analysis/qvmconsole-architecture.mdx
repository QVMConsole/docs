# QVMConsole 架构设计

本页面主要是展示QVMConsole程序技术公开。

## 整体架构

QVMConsole 采用前后端分离架构，后端基于 Go 语言，前端使用 Vue.js 3。

```mermaid
graph TB
    subgraph 客户端
        Browser[浏览器]
    end

    subgraph 前端应用
        Vue[Vue.js 3 + Vite]
        Pinia[Pinia 状态管理]
        ElementPlus[Element Plus UI]
    end

    subgraph 后端服务
        Gin[Go Gin HTTP 服务]
        Middleware[中间件层]
        Router[路由层]
        Handler[Handler 处理层]
        Service[Service 业务层]
        TaskQueue[任务队列]
    end

    subgraph 数据层
        SQLite[SQLite 数据库]
        Libvirt[libvirt API]
        System[系统命令]
    end

    Browser --> Vue
    Vue --> Pinia
    Vue --> ElementPlus
    Vue -->|HTTP API| Gin
    Gin --> Middleware
    Middleware --> Router
    Router --> Handler
    Handler --> Service
    Service --> TaskQueue
    Service --> SQLite
    Service --> Libvirt
    Service --> System
```

## 后端架构

### 技术栈

| 组件 | 技术 | 说明 |
|------|------|------|
| Web 框架 | Gin | 高性能 HTTP 框架 |
| 虚拟化 API | libvirt | 虚拟机管理接口 |
| 数据库 | SQLite | 轻量级嵌入式数据库 |
| 任务队列 | 自研 | 基于 goroutine 的异步任务系统 |

### 请求处理流程

```mermaid
sequenceDiagram
    participant Client as 客户端
    participant Gin as Gin 路由
    participant Auth as 认证中间件
    participant Handler as Handler
    participant Service as Service
    participant DB as SQLite
    participant Libvirt as libvirt

    Client->>Gin: HTTP 请求
    Gin->>Auth: 验证 Token
    Auth->>Handler: 解析参数
    Handler->>Service: 调用业务逻辑
    Service->>DB: 读写数据库
    Service->>Libvirt: 管理虚拟机
    Service-->>Handler: 返回结果
    Handler-->>Client: JSON 响应
```

### 中间件系统

| 中间件 | 功能 | 应用范围 |
|--------|------|----------|
| `CORSMiddleware` | 处理跨域请求 | 全局 |
| `AuthMiddleware` | JWT 令牌验证 | 需要认证的接口 |
| `AdminMiddleware` | 管理员权限验证 | 管理员接口 |
| `VMAccessMiddleware` | VM 归属权限验证 | VM 操作接口 |
| `ElasticCloudOnlyMiddleware` | 弹性云功能限制 | 弹性云专属功能 |
| `TokenTypeMiddleware` | 令牌类型验证 | 特定类型接口 |

| `reinstall` | 重装系统 | ❌ |

## 虚拟化集成

### libvirt 交互

```mermaid
sequenceDiagram
    participant QVM as QVMConsole
    participant Lib as libvirt
    participant QEMU as QEMU/KVM
    
    QVM->>Lib: Connect("qemu:///system")
    Lib-->>QVM: Connection Handle
    
    QVM->>Lib: LookupVM("vm-name")
    Lib-->>QVM: Domain Handle
    
    QVM->>Lib: Start()
    Lib->>QEMU: 启动 VM
    
    QVM->>Lib: GetVMInfo()
    Lib->>QEMU: 查询状态
    Lib-->>QVM: VM 信息
```

### 支持的虚拟化操作

| 操作 | libvirt API | 说明 |
|------|-------------|------|
| 创建 VM | `DefineXML` + `Create` | 定义并启动 |
| 关机 | `Shutdown` / `Destroy` | 正常/强制关机 |
| 暂停 | `Suspend` | 暂停 VM |
| 恢复 | `Resume` | 恢复运行 |
| 快照 | `SnapshotCreateXML` | 创建快照 |
| 迁移 | `MigrateToURI` | 跨节点迁移 |
| 克隆 | `DefineXML` + 磁盘复制 | 克隆 VM |

## SSE 实时推送

QVMConsole 使用 Server-Sent Events 实现实时数据推送：

```mermaid
sequenceDiagram
    participant Client as 浏览器
    participant API as API 服务
    
    Client->>API: GET /api/vm/sse
    API-->>Client: SSE 连接建立
    
    loop 实时推送
        API-->>Client: VM 状态更新
        API-->>Client: 任务进度
    end
    
    Client->>API: 关闭连接
```

### SSE 端点

| 端点 | 推送内容 |
|------|----------|
| `/api/vm/sse` | VM 列表状态 |
| `/api/vm/:name/sse` | 单个 VM 详情 |
| `/api/host/stats/sse` | 宿主机资源 |
| `/api/task/sse` | 任务进度 |
| `/api/scheduler/events/sse` | 调度事件 |
