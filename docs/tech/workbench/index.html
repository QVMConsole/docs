工作台

工作台（路由 /dashboard）是登录后的默认首页，按角色展示不同内容：管理员看宿主机监控与平台统计，普通用户看个人配额与我的虚拟机。页面顶部标签中工作台为固定标签，不可关闭。

管理员工作台​

宿主机监控​

宿主机资源监控通过 SSE 实时推送（GET /host/stats/sse，5 秒间隔；首屏先拉取一次 HTTP 数据，SSE 断线 5 秒自动重连）：

监控项说明
CPU 使用率总体与各物理核使用率（/host/cpu/hardware 提供 CPU 型号与每核数据）
内存总量/已用/缓存，含内存条明细（/host/memory/modules：插槽、容量、频率、类型）
磁盘磁盘列表与读写速率（/host/disks）
网络收发速率实时曲线
历史曲线/host/stats/history 提供历史监控数据

监控数据由后台采集器每 10 秒采集、每 60 秒持久化到 host_stats_records。

平台统计​

统计项说明
资源总览卡片虚拟机数量、运行中数量、CPU/内存/磁盘分配与使用概览
宿主机状态横幅维护模式、异常状态等全局提示
底部统计区用户数、存储池、网络等资源汇总

用户工作台​

配额概览​

GET /self/quota 返回当前用户的配额与用量：

配额项说明
CPU / 内存 / 磁盘核心配额与已用量（进度条展示）
虚拟机数量允许创建的 VM 数量
存储 / 快照 / 端口转发其余资源配额
运行时长 / 流量 / 带宽按配置的限额展示（0 表示不限）

配额使用率超过阈值时以颜色提醒（70% 黄色、90% 红色）。

我的虚拟机跟踪​

GET /self/vms（含 SSE 实时推送 /self/vms/sse）展示名下虚拟机的运行状态与资源条，点击跳转虚拟机详情。
